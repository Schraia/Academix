# contact-center-dashboard

## Overview
Portfolio project for contact center KPI analysis using BigQuery SQL and a Looker Studio dashboard.

## Data note
This dataset is synthetic and generated by `generate_data.py`.

## Schema (`cc_analytics.calls`)
- `call_id` STRING
- `call_start` TIMESTAMP
- `queue` STRING
- `agent_id` STRING
- `wait_sec` INT64
- `handle_sec` INT64
- `abandoned` BOOL
- `resolved_first_call` BOOL
- `csat` INT64 (nullable)

## KPI definitions
- Total calls: count of calls.
- Abandonment rate: abandoned calls / total calls.
- Avg handle time: mean `handle_sec` for answered calls.
- Avg wait: mean `wait_sec`.
- Service level (20s): answered calls with wait <= 20s / answered calls.
- FCR rate: resolved on first call / answered calls.
- Avg CSAT: mean `csat` where available.

## How to run
1. Generate CSV data:
   - `python generate_data.py`
2. Load `data/calls.csv` into BigQuery sandbox as `cc_analytics.calls`.
3. Run SQL files in order:
   - `sql/01_clean.sql`
   - `sql/02_kpis.sql`
   - `sql/03_agents.sql`
   - `sql/04_trends.sql`
4. Connect Looker Studio to BigQuery views/tables and build visuals.
